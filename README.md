# 야, 너도 들을 수 있어! — 소리로 만나는 생물다양성 퀴즈

지구를지키는시학교 활동지와 함께 쓰는 보령 소리 퀴즈 웹페이지입니다. (교사용, 모바일 우선)

## 화면
`index.html` 한 화면에 동그라미 5개(위 2 · 가운데 1 · 아래 2).
- 동그라미를 누르면 소리 재생, 바깥 고리가 시계 방향으로 진행 정도 표시 (한 번에 하나)
- 하단 「정답 확인」을 누르면 그 자리에서 동그라미가 차례로 뒤집혀 정답 공개
- 「문제 섞기」로 순서를 랜덤으로 바꿈 (새로고침해도 유지)
- `answer.html`은 예전 주소용 — `index.html#answer`로 이동

## 정답·순서 바꾸기
`app.js` 맨 위 `ANIMALS`에서 관리합니다. 키는 녹음 파일 번호(`audio/soundN.mp3`)입니다.

## 오프라인
`sw.js`가 처음 열 때 화면·소리·사진·글꼴을 저장해 두어, 이후 인터넷이 끊겨도 동작합니다.
**소리·사진을 바꾸면 `sw.js`의 `VERSION`을 올려야** 휴대폰에 새 파일이 반영됩니다.

## 파일
- `img/` 활동지에서 잘라낸 동물 사진, `silhouette.png`(박새 실루엣)
- `audio/` 녹음 파일

## 실행 · 배포
빌드 없는 정적 사이트입니다. 로컬 확인은 `python3 -m http.server` 후 브라우저로 열고, 배포는 Netlify입니다.
