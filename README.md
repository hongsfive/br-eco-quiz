# 야, 너도 들을 수 있어! — 소리로 만나는 생물다양성 퀴즈

지구를지키는시학교 활동지와 함께 쓰는 보령 소리 퀴즈 웹페이지입니다. (교사용, 모바일 우선)

## 화면
- `index.html` 소리 퀴즈 — 번호별 소리 재생(한 번에 하나), 「문제 섞기」로 순서를 랜덤으로 바꿈
- `answer.html` 정답 — 실루엣 카드를 눌러 뒤집으면 정답 동물 공개, 「모두 뒤집기」 지원

## 정답·순서 바꾸기
`app.js` 맨 위 `ANIMALS`에서 관리합니다. 키는 녹음 파일 번호(`audio/soundN.mp3`)입니다.
섞인 순서는 정답 링크의 `?q=` 값과 브라우저 탭(sessionStorage)으로 정답 화면에 넘어갑니다.

## 파일
- `img/` 활동지에서 잘라낸 동물 사진, `silhouette.png`(박새 실루엣)
- `audio/` 녹음 파일

## 실행 · 배포
빌드 없는 정적 사이트입니다. 로컬 확인은 `python3 -m http.server` 후 브라우저로 열고, 배포는 Netlify입니다.
